# LLM Gateway — свой API-шлюз к нейросетям (аналог OpenRouter)

Один OpenAI-совместимый API-ключ → доступ к моделям OpenAI, Anthropic, Gemini, DeepSeek, xAI, Mistral, Groq, OpenRouter и любым OpenAI-совместимым провайдерам. Баланс в USD, оплата через Platega и CryptoBot, полная админка.

## 1. Запуск на сервере (VPS, Ubuntu 22.04+)

1. Купите домен и создайте A-запись `api.ваш-домен.ru` → IP сервера.
2. Установите Docker: `curl -fsSL https://get.docker.com | sh`
3. Загрузите папку проекта на сервер и выполните:

```bash
cd llm-gateway
cp .env.example .env
nano .env            # укажите DOMAIN, PUBLIC_URL, ADMIN_EMAIL, ADMIN_PASSWORD, POSTGRES_PASSWORD
docker compose up -d --build
```

Через 1–2 минуты сайт откроется по `https://ваш-домен` (сертификат выпускается автоматически).

Главная страница — сразу экран входа через GitHub и Google. Админ входит по паролю на скрытой странице **`https://ваш-домен/#/admin-login`** (`ADMIN_EMAIL` / `ADMIN_PASSWORD` из `.env`). Если админ войдёт через GitHub/Google с адресом `ADMIN_EMAIL`, он тоже получит права админа.

Обновление: `docker compose up -d --build`. Логи: `docker compose logs -f app`.
Бэкап базы: `docker compose exec db pg_dump -U gateway gateway > backup.sql`.

> Ключи шифрования генерируются при первом запуске и лежат в томе `appdata` (`/app/data/secrets.json`). **Не удаляйте этот том** — без него сохранённые ключи провайдеров и платёжек не расшифруются.

Локальный запуск без Docker (SQLite):
```bash
pip install -r requirements.txt
ADMIN_EMAIL=admin@local ADMIN_PASSWORD=admin123 uvicorn app.main:app --port 8000
```

## 2. Добавление моделей

Админка → **Провайдеры** → «Добавить провайдера» → выберите пресет (OpenAI, Anthropic, …) → вставьте API-ключ(и) → «Проверить» → «Импорт моделей».
Цены подтягиваются из справочника, проверьте их на сайте провайдера. В разделе **Модели** можно задать свою цену продажи или общую наценку (Настройки → Биллинг).
Несколько ключей у провайдера ротируются автоматически; при 429 ключ ставится на паузу, при 401/403 — отключается. У модели можно указать несколько маршрутов (fallback).

## 3. Вход через GitHub и Google

Админка → **Настройки** → блоки «Вход через GitHub» и «Вход через Google». Кнопка входа появится на главной, как только заполнены Client ID и Secret (их также можно задать в `.env`: `GITHUB_CLIENT_ID`, `GITHUB_CLIENT_SECRET`, `GOOGLE_CLIENT_ID`, `GOOGLE_CLIENT_SECRET`).

- **GitHub:** https://github.com/settings/developers → OAuth Apps → New OAuth App. Homepage URL = адрес сайта, Authorization callback URL = `https://ваш-домен/api/auth/oauth/github/callback`.
- **Google:** https://console.cloud.google.com → APIs & Services → OAuth consent screen (тип External, опубликовать) → Credentials → Create OAuth client ID → Web application. Authorized redirect URI = `https://ваш-домен/api/auth/oauth/google/callback`.

Аккаунт создаётся при первом входе (используется подтверждённый email), сразу выдаётся первый API-ключ.

## 4. Подключение оплаты

Админка → **Настройки**.

### Platega
1. В личном кабинете Platega возьмите **Merchant ID** и **Secret (API-ключ)**.
2. Вставьте их во вкладке «Platega», включите метод, укажите курс USD→RUB и способ оплаты (СБП/карта).
3. Скопируйте показанный **Callback URL** (`https://ваш-домен/api/pay/webhook/platega`) и укажите его в кабинете Platega.

### CryptoBot (@send)
1. В Telegram откройте [@send](https://t.me/send) → Crypto Pay → Create App → скопируйте **API Token**.
2. Вставьте токен во вкладке «CryptoBot», включите, нажмите «Проверить».
3. В @send → Crypto Pay → My Apps → ваше приложение → Webhooks → вставьте **Webhook URL** (`https://ваш-домен/api/pay/webhook/cryptobot`).

Если вебхук не дошёл — пользователь может нажать «Проверить оплату», а админ — «Проверить» или «Зачислить вручную» в разделе Платежи. Повторное зачисление исключено.

## 5. Использование API

```bash
curl https://ваш-домен/v1/chat/completions \
  -H "Authorization: Bearer sk-gw-..." -H "Content-Type: application/json" \
  -d '{"model":"gpt-4o-mini","messages":[{"role":"user","content":"Привет"}]}'
```

```python
from openai import OpenAI
client = OpenAI(base_url="https://ваш-домен/v1", api_key="sk-gw-...")
print(client.chat.completions.create(model="claude-sonnet-4", messages=[{"role":"user","content":"Hi"}]).choices[0].message.content)
```

Эндпоинты: `/v1/chat/completions` (в т.ч. stream), `/v1/responses` (Responses API — нужен Codex CLI), `/v1/messages` и `/v1/messages/count_tokens` (Anthropic-формат — Claude Code), `/v1/embeddings`, `/v1/models`, `/v1/balance`.

Claude Code и Codex CLI: готовые настройки — в кабинете, раздел «Документация». Для моделей не от OpenAI шлюз переводит Responses API в их формат; заголовки `anthropic-beta`/`anthropic-version` уходят провайдеру Anthropic как есть. Кеш промптов тарифицируется отдельно: по умолчанию чтение — 10% цены входа у Anthropic и 50% у остальных, запись — 125% у Anthropic; доли можно задать для каждой модели.

Кабинет клиента показывает деньги в рублях по курсу «рублей за $1» из настроек биллинга (баланс по-прежнему хранится в USD, поэтому после смены курса суммы в кабинете пересчитаются). У каждого API-ключа можно задать лимит расходов на всё время, сутки или месяц (по московскому времени), список разрешённых моделей, срок действия и свой лимит запросов в минуту; `/v1/balance` показывает состояние ключа и причину, если запросы не пройдут. Swagger: `/api/docs`.

## 6. Важно
- Перепродажа доступа к API может противоречить условиям OpenAI/Anthropic и др. — проверьте условия провайдеров (или используйте агрегаторы/провайдеров, разрешающих реселлинг).
- Перепроверяйте цены моделей: справочные цены могут устареть.
- Перед приёмом платежей оформите юридическую сторону (самозанятость/ИП, оферта, политика конфиденциальности).
- SEO: `/models` и `/models/<id>` — страницы моделей с ценами, `/robots.txt`, `/sitemap.xml`; главная отдаётся с серверной копией лендинга (код в `app/seo.py`). Для корректных ссылок в поиске задайте `PUBLIC_URL`.
- В `static/privacy.html`, `static/terms.html` и `static/index.html` метки `{{SITE_NAME}}`, `{{DOMAIN}}`, `{{PUBLIC_URL}}`, `{{YEAR}}` подставляются сервером из «Название сайта» в админке и `PUBLIC_URL`.

## Новое в этой версии

### Поддержка (тикеты)
- Пользователь: вкладка «Поддержка» → «Новое обращение» (заголовок, тема, подробности, вложения). Обращение можно отменить, дописать, закрыть как решённое или открыть снова.
- Вложения: файлы, перетаскивание, вставка Ctrl+V, «Скриншот экрана» и «Записать видео экрана» (до 3 мин, в десктопных браузерах). Лимиты: картинки/PDF/TXT до 10 МБ, видео (mp4/mov/webm) до 100 МБ, 500 МБ в день на пользователя. Тип проверяется по содержимому, ссылки на файлы подписаны.
- Админ: вкладка «Поддержка» (Ждут ответа / Все открытые / Закрытые / Все, поиск по теме, email, #номеру), ответ с вложениями, «Ответить и закрыть», закрыть/открыть тикет, карточка пользователя.
- Красные счётчики непрочитанного в меню у пользователя и админа, автообновление переписки раз в 30 с.
- Файлы хранятся в `DATA_DIR/support` (в Docker — volume `appdata`). Таблицы создаются автоматически.

- **Понятные ошибки** — все ошибки API на русском, с подсказкой что делать и ссылкой в кабинет (ключи, баланс, каталог). При опечатке в названии модели предлагаются похожие.
- **Каталог моделей** — поиск, фильтры (провайдер, картинки, функции), сортировка, метка «Популярная» (топ-3 за 7 дней), сравнение до 3 моделей.
- **Калькулятор стоимости** — вкладка в «Модели и цены»: вставьте текст, укажите длину ответа и число запросов.
- **Готовые настройки** — в «Документации»: Cursor, Continue, SillyTavern, LibreChat, n8n, LangChain, Open WebUI. Для Cursor нужен публичный HTTPS-адрес (`PUBLIC_URL`).
- **Playground** — история чатов (в браузере), картинки, системный промт, сравнение двух моделей, кнопка «Стоп».
- **Расходы** — страница с фильтром по датам, графиком, разбивкой по ключам и моделям, выгрузкой в CSV (открывается в Excel).
- **PDF-квитанции** — для оплаченных пополнений (кабинет → Баланс; админка → Платежи). Реквизиты продавца задаются в админке: Настройки → «Реквизиты для квитанций». Квитанция не является фискальным чеком.
- **Пригласи друга** — страница «Пригласить друга» с личной ссылкой. Друг получает $0.50 при регистрации по ссылке, пригласивший — $1 (по умолчанию после первого пополнения друга, чтобы фейковые аккаунты ничего не приносили). Суммы и условие меняются в админке: Настройки → «Пригласи друга».
- **Бонус к пополнению** — от $50 +5%, от $200 +10% (админка → Биллинг → «Бонус к пополнению», формат `50:5, 200:10`). Бонус виден до оплаты, указан в PDF-квитанции и списывается обратно при возврате платежа.
- **Страница статуса** — `/#/status`, открывается без входа (ссылка внизу страницы входа и в меню кабинета). Для каждой модели: работает ли сейчас (по последним 30 минутам), доступность, процент ошибок и средняя задержка за 24 часа, полоска по часам. Считаются только сбои сервиса/провайдеров (5xx), ошибки клиента не учитываются. Названия провайдеров не показываются. Отключается в админке: Настройки → «Публичная страница статуса».

Обновление: новая зависимость `fpdf2`, поэтому пересоберите контейнер — `docker compose up -d --build`. Миграции БД не нужны.

## Языки интерфейса / UI languages

Кабинет доступен на русском и английском — переключатель RU / EN в шапке, на странице входа и на странице статуса. Язык по умолчанию определяется по браузеру и запоминается в `localStorage`. Словарь переводов — `static/i18n.js` (`DICT`): интерфейс написан на русском, а в английском режиме фразы подменяются при выводе. Новую строку достаточно добавить в `DICT`.

## Главная страница

Публичная главная (`#/`) — `static/landing.js` + `static/landing.css`: hero с живой схемой маршрутизации запросов, подключение (diff `base_url` для Python / Node.js / curl), три шага, оплата, FAQ и статус моделей (данные из `/api/public/status`; блок скрывается, если страница статуса выключена). Вход и регистрация открываются в модальном окне (`#/login` открывает его сразу — сохранено для OAuth-редиректов с ошибкой).
