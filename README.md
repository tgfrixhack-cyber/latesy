## Блок-Арена (PvP)

Кубический PvP до последнего выжившего: 2–12 игроков, круглый остров над морем, потолок 20 блоков. Раунд 6 минут: первый баф для всех на 30-й секунде, дальше новый каждую минуту. Край острова — обрыв: упал — выбыл, а убийство засчитывается тому, кто сбросил (если ударил в последние 8 с). С 2-й минуты остров осыпается с краёв ступенями (48 → 40 → 32 → 24 → 18 → 12), клетки перед обвалом 10 с мигают красным. После 6:00 — овертайм: любой удар убивает, регенерации нет, остров сжимается до 3; через минуту побеждает лучший из живых по убийствам, затем урону. Первая кровь, серии убийств (3, 5, 7), прерванная серия и двойное убийство объявляются на весь экран, игроки с 3+ убийствами горят.

- `npm run dev` — сайт и игровой сервер (WebSocket `/game-ws`) на одном порту, http://localhost:3000
- `npm run build && npm start` — то же в production
- `npm run game` — только игровой сервер (если сайт раздаётся статикой, например с GitHub Pages)

Игровой сервер запускается через встроенный в Node запуск TypeScript, нужен Node 22.18+.
Если сайт и сервер живут на разных хостах, при сборке сайта укажите `NEXT_PUBLIC_GAME_SERVER_URL=wss://ваш-сервер/game-ws`.
`PVP_TIME_SCALE=0.1` ускоряет раунд в 10 раз (удобно для тестов). Для проверки отдельных механик: `PVP_MODE=sumo` фиксирует режим, `PVP_BUFFS=night,lava,meteors` — порядок бафов.

Код: `server/` — сервер раундов, `src/game/shared.ts` — общие правила и протокол, `src/game/client/` — движок на Three.js, `src/components/pvp/` — интерфейс.

### Режимы

Девять режимов, за них голосуют площадками в хабе:

- **Классика, Ваншот, Низкая гравитация, Строители** — до последнего выжившего.
- **Заражение** — примерно каждый четвёртый начинает зомби. Убитый человек становится зомби и возрождается через 3 с. Зомби бьют на 25% сильнее. Люди побеждают, если кто-то из них доживёт до 6:00, зомби — когда людей не осталось.
- **Царь горы** — в центре острова золотой круг. Кто стоит в нём один, получает очко в секунду; 60 очков — победа, иначе по очкам на 6:00. Возрождение через 3 с.
- **Сумо** — остров радиусом 11, урона нет, только отбрасывание ×1.5, строить нечем. Упал — выбыл.
- **Сплиф** — пола нет: два снежных слоя (y 0 и 4) над пропастью. Урона нет, ломай снег под соперниками. Сломанный снег не даёт блоков.
- **Команды** — красные против синих (поровну), стартуют на своих сторонах. Своих не бить, возрождение через 3 с. Побеждает команда, первой набравшая 4 убийства на игрока большей команды. При равенстве на 6:00 — овертайм до первого убийства.

### Бафы

Новый баф каждую минуту с 0:30. Последний слот раунда — **Хаос**: два совместимых бафа сразу, держатся до конца овертайма. У каждого бафа свой цвет неба и краёв экрана, свой звук и полоска оставшегося времени. Выбывшие в режимах на выбывание голосуют за следующий баф: три варианта, клавиши 1–3.

- **Гравитация, Скорость, Ваншот, Двойной прыжок, Стройка** — как раньше.
- **Вампиризм** — урон лечит, убийство даёт полное здоровье и +1 сердце сверху (до +5).
- **Ночь** — темнота и туман на 26 блоков, ники видны сквозь стены. Сервер не присылает игроков дальше 18 блоков.
- **Пол — лава** — пол жжёт, лава поднимается на блок каждые 20 с (до 3) и убивает: 2 HP в секунду.
- **Бейсбол** — отбрасывание ×3 и подброс вверх. У края — смертельно.
- **Невидимость** — все почти прозрачны и не отбрасывают тени, бегущие оставляют следы. Удар выдаёт на секунду. Сервер не присылает игроков дальше 14 блоков.
- **Берсерк** — урон растёт с потерей здоровья, до ×3.
- **Охота за головой** — лидер по убийствам виден всем сквозь стены и отмечен маркером. Убивший его получает +8 земли и полное здоровье, а потом сам становится целью.
- **Горячая картошка** — у случайного игрока бомба с фитилём 20 с. Удар передаёт её; сразу вернуть тому, кто передал, нельзя 1.5 с. Взрыв убивает держателя (убийство засчитывается передавшему), ранит в радиусе 4 и ломает блоки.
- **Метеориты** — каждые 1.5 с камни падают рядом с игроками. Красный круг предупреждает за 2 с, удар ранит в радиусе 2.4 и ломает блоки.
- **Обмен** — каждые 15 с все живые меняются местами, за 3 с предупреждение.
- **Великаны и малыши** — половина игроков в 1.6 раза больше (30 HP, урон ×1.5, отбрасывание по ним ×0.6, скорость ×0.9), половина в 0.6 раза меньше (14 HP, урон ×0.75, отбрасывание ×1.4, скорость ×1.15). Хитбокс, глаза и дальность меняются, коллизия с блоками остаётся обычной.
- **Гололёд** — на земле сцепление как в воздухе, тормозить трудно.
- **Луки** — у каждого 5 стрел, Q — выстрел (4 урона, отбрасывание).

### Лобби-хаб

Лобби — отдельная карта того же размера, что и арена (круг радиусом 48). Хаб работает всегда, раунд идёт параллельно с ним: кто ждёт, ходит по хабу, кто играет — на арене. Карта хаба собирается в коде (`HUB` и `hubBlocks()` в `src/game/shared.ts`), украшения и табло рисует `src/game/client/hub-scene.ts`, скелетов ведёт `server/mobs.ts`.

- **Зоны.** Зелёный круг «Готов» у портала, девять площадок голосования за режим, манекены, загон с ходячими скелетами, обрыв со скелетами «Сбей меня!», вышка лучника (стрелы без урона), тир на 30 секунд, паркур с таймером, площадка для стройки (блоки исчезают через минуту), яма для дуэлей, гардероб, пьедестал победителя, табло арены и доска рекордов дня.
- **Старт раунда.** Когда в хабе двое активных игроков, идёт таймер 60 с. Если в круге больше половины, старт через 10 с. Кто минуту ничего не нажимал или дерётся на дуэли, в подсчёт не входит и на арену не попадает. В раунде до 12 игроков, остальные ждут в хабе и в следующем раунде получают приоритет. Участники падают с неба на свои точки во время отсчёта.
- **После раунда.** Все возвращаются в хаб, победитель встаёт на пьедестал и носит корону до конца следующего раунда. У всех экран итогов с наградами: «Убийца», «Мясник», «Король критов», «Главный строитель».
- **Тренировка честная.** Удары по скелетам проходят ту же проверку, что и в бою (дальность, стены, кулдаун, крит только в падении), а при промахе сервер подсказывает, почему удар не засчитан. Слева внизу видна статистика: удары, процент критов, серия, урон в секунду.
- **Оформление** (только на клиенте, без коллизий, на сервер не влияет, `src/game/client/scenery.ts`): небо с градиентом и квадратным солнцем, море внизу, каменное «днище» острова, летающие острова с деревьями. Победителю — салют над пьедесталом и на экране итогов, вокруг короны сыплются искры.
- **Рекорды дня** (победы, убийства, тир, паркур; день по Москве) хранятся в `data/records.json`. Путь меняет `PVP_RECORDS_FILE`. Процессу игры нужно право записи в эту папку.

| Клавиша | Что делает |
| --- | --- |
| WASD, Пробел, мышь | ходьба, прыжок, обзор |
| W W (дважды быстро) | спринт, как в Minecraft |
| V | вид от первого / третьего лица (в режиме наблюдения V переключает камеры, как раньше) |
| ЛКМ / ПКМ | удар или сломать блок / поставить землю (в хабе только на площадке для стройки) |
| T | смотреть идущий раунд из хаба и обратно; выбывшему — вернуться в хаб |
| E | гардероб (рядом со стойкой): цвет и облик, выбор запоминается в браузере |
| F | вызвать на дуэль игрока под прицелом (до 8 блоков) |
| Y / N | принять / отказать |
| H | помощь по зонам хаба |
| M | звук |
| V, Q/E, ЛКМ/ПКМ | в режиме наблюдения: вид камеры, следующий / предыдущий игрок |

**Спринт** устроен как в Minecraft (Java): второе нажатие W в течение 350 мс (7 тиков), стоя на земле. Бег на 30% быстрее, обзор расширяется на 15%, при каждом прыжке с земли толчок вперёд, так что бег с прыжками ещё примерно на 30% быстрее. Спринт сбивается, если отпустить W или нажать S, врезаться в стену (скольжение вдоль стены под углом до 8° не считается) или ударить кого-то. Удар с разбега отбрасывает примерно в 2,5 раза дальше и выше, но не бывает критом; бьющий при этом теряет 40% скорости. Сервер учитывает спринт в проверке движения: клиент сообщает флаг `sp` (был ли спринт с прошлого сообщения), скорость спринта разрешается и ещё 1,5 с после него, толчок от прыжка засчитывается только за настоящий прыжок с земли. Усиленное отбрасывание даётся, только если игрок действительно разбегался.

**Скины** нарисованы в раскладке скина Minecraft 64×64, но в двойном разрешении (HD-скин 128×128, лицо 16×16 вместо 8×8), прорисованы все грани, включая кисти, ступни и макушку. Второй слой (волосы, капюшон, шлем, латы, обмотки) — чуть увеличенные коробки поверх, как слой «шапки» и «куртки» в Minecraft, сквозь прорези видно то, что под ним. Текстуры персонажей без мипмапов, поэтому чёткие и вблизи, и вдали. Код — `src/game/client/skins.ts`.

**Меч** сделан как в Minecraft Java: спрайт 16×16, выдавленный в объём на 1 пиксель, держится и взмахивает по тем же формулам (ItemInHandRenderer, `item/handheld.json`, HumanoidModel). Взмах длится 6 тиков (0,3 с) и идёт справа налево вниз к прицелу. В стиле 1.9+ меч после удара опускается и поднимается к концу перезарядки. От первого лица меч рисуется отдельно с постоянным обзором 70°, поэтому не растягивается при спринте и не уходит в стены. Материал (дерево, камень, железо, золото, алмаз, незерит), зачарование и стиль анимации (1.9+ или 1.8) задаются в `src/game/client/sword.ts`.

**Мышь.** В Chrome, Edge и других браузерах на Chromium игра захватывает мышь без ускорения ОС (`unadjustedMovement`), поэтому поворот зависит только от движения руки. Заодно это убирает рывки камеры на Windows с мышами 500–1000 Гц ([баг Chromium](https://issues.chromium.org/issues/40662608)). Где такой режим недоступен (Firefox, Safari), одиночные дикие скачки размером в полэкрана отбрасываются. Чувствительность (0.2–3×) настраивается на экране входа и в помощи (H) и запоминается в браузере. Тряска камеры при ударах только наклоняет картинку и не сдвигает прицел.

### Античит

Клиенту сервер не верит: всё проверяется в `server/anticheat.ts` и `server/game.ts`.

- **Движение.** Клиент присылает позицию, вертикальную скорость и часы своей физики. Сервер прогоняет это через ту же физику (`stepBody` в `shared.ts`) и не пропускает спидхак, полёт, зависание, высокий прыжок, проход сквозь блоки, ускорение времени и выход за кольцо. Нарушителя возвращает назад (`tp`), летуна опускает на землю. Подбрасывание при отбрасывании тоже должно появиться: игнор отбрасывания засчитывается как нарушение.
- **Лаги не наказываются.** Каждое движение несёт номер последнего полученного тика, и сервер проверяет его по тому, что клиент уже видел: баф, край острова, блоки. Пачка сообщений после подвисания сети не считается читом, её максимум мягко поправит без штрафа.
- **Удары.** Луч из глаз атакующего по присланному взгляду должен попасть в цель там, где атакующий её видел (откат по номеру тика). Ещё проверяются дальность, стены на пути и кулдаун. Крит засчитывается только при настоящем падении.
- **Стройка.** Дальность, блок под прицелом (не сквозь стену), кулдаун.
- **Против ESP.** Пока действует туман или невидимость, игроки вне видимости вообще не отправляются клиенту. Вторая вкладка-зритель с того же IP видит столько же, сколько живой игрок.
- **Сеть.** Лимит сообщений, подключений с одного IP и переподключений, проверка версии клиента. Лимиты и баны по IP работают, только когда известен настоящий IP игрока: за nginx нужен `X-Forwarded-For`, см. ниже. Без него игроки неразличимы, и лимиты отключаются, чтобы бан одного не задел всех.
- **Наказания.** Нарушения дают очки, которые сгорают вдвое за минуту. При 30 очках следует кик, после второго кика за полчаса — бан IP на 15 минут. Каждое нарушение пишется в лог сервера строкой `[anticheat] …`.

Настройки (переменные окружения игрового сервера):

| Переменная | По умолчанию | Что делает |
| --- | --- | --- |
| `PVP_AC_KICK` | `1` | `0` — только исправлять и логировать, без киков и банов |
| `PVP_AC_KICK_VL` | `30` | порог очков для кика |
| `PVP_AC_BAN_MINUTES` | `15` | длина бана после второго кика, `0` — без банов |
| `PVP_MAX_CONN_PER_IP` | `4` | подключений с одного IP, `0` — без лимита (школа/общий NAT) |
| `PVP_MAX_CLIENTS` | `100` | всего подключений |
| `PVP_ALLOWED_ORIGINS` | пусто | список сайтов через запятую, которым можно подключаться, например `https://example.github.io` |
| `PVP_CLIENT_IP_HEADER` | пусто | заголовок с IP игрока за CDN, например `cf-connecting-ip`. За локальным nginx берётся `X-Forwarded-For` |
| `PVP_RECORDS_FILE` | `data/records.json` | файл рекордов дня |

`npm test` гоняет все тесты сервера, `npm run test:hub` — только хаб (вход, круг «Готов» и автостарт, голосование, скелеты и криты, тир, паркур, дуэли, просмотр раунда по T, пьедестал и корона, стройка). `npm run test:anticheat` гоняет тесты античита: честные боты играют полные раунды, в том числе на плохом мобильном интернете с подвисаниями по 1–3 с, и не должны получить ни одного штрафа. Читерские боты (скорость, полёт, noclip, таймер, дальность, килл-аура, удары сквозь стену, фейковые криты, игнор отбрасывания, флуд, ESP) должны быть пойманы. В хабе античит проверяет ходьбу, удары и стройку так же, как на арене. Сайт и сервер обновляйте вместе: версия протокола сейчас 4 (хаб и спринт), старый клиент получит сообщение «обновите страницу».

### Запуск на сервере и лаги

На сервере только production-режим (Node 22.18+):

```bash
npm ci
npm run build
PORT=3000 npm start      # сайт и игра; держите запущенным через systemd или pm2
```

`npm run dev` на сервере заставляет игру лагать: Next.js компилирует страницы на лету в том же процессе, что и игра. Сервер предупреждает об этом при старте.

nginx перед игрой (HTTPS настраивается как обычно, например через certbot):

```nginx
location /game-ws {
    proxy_pass http://127.0.0.1:3000;
    proxy_http_version 1.1;
    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_read_timeout 1h;
}
location / {
    proxy_pass http://127.0.0.1:3000;
    proxy_set_header Host $host;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
}
```

Если игроки жалуются на лаги:

- **«Пинг N мс» в правом нижнем углу** показывает задержку до сервера. Если у всех больше ~150 мс, сервер далеко от игроков: нужен VPS поближе к ним.
- **`[pvp] server stalled for N ms` в логе** означает, что подвисал сам сервер: слабый или перегруженный VPS, нехватка памяти (своп) или dev-режим. Для сравнения, 12 игроков занимают примерно 1–2% одного ядра и около 7 КБ/с трафика на игрока.
- **Cloudflare.** Если домен проксируется через Cloudflare (оранжевое облако), российские провайдеры режут такие соединения примерно до 16 КБ, и у игроков из России игра обрывается ([Cloudflare](https://developers.cloudflare.com/support/troubleshooting/general-troubleshooting/service-disruption/)). Для домена игры прокси нужно выключить (серое облако, DNS only).
